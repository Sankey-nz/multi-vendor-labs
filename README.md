## About

This repository contains hands-on network engineering labs built in PNetLab using real Cisco IOS images. Each lab demonstrates practical skills through real device configuration, troubleshooting, and verification — not simulations. The focus is on CCNA-level topics and beyond, built to reflect the kind of work done in production enterprise environments.
